# Vehicle Emissions and Air Quality Analysis

Data visualisation and exploratory data analysis project investigating the relationship between motor vehicle growth and air quality trends across U.S. states between 2010 and 2020.

The project combines multiple datasets to analyse how increasing vehicle volumes may relate to changes in Median AQI (Air Quality Index) values using interactive visualisations and geospatial analysis.

---

## Project Overview

This project focuses on:
- Cleaning and preprocessing real-world datasets
- Merging multi-source datasets
- Exploratory Data Analysis (EDA)
- Interactive data visualisation
- Geospatial mapping of environmental data

The analysis was performed using Python and visualisation libraries including Plotly and Seaborn.

---

## Key Features

- Data cleaning and preprocessing using Pandas
- Dataset merging and transformation
- Interactive scatter plots
- Animated visualisations across years
- Choropleth maps for AQI trends by state
- Comparative analysis between vehicle counts and air quality

---

## Technologies Used

- Python
- Pandas
- Plotly
- Seaborn
- Jupyter Notebook

---

## Dataset Information

The project combines:
- Motor vehicle registration data, Kaggle: https://www.kaggle.com/datasets/adampq/air-quality-index-by-state-1980-2022
- Air Quality Index (AQI) data, data.transport.gov: https://data.transportation.gov/Roadways-and-Bridges/Motor-Vehicle-Registrations-1900-2023-MV-1-wide-fo/hwtm-7xmz

Data was analysed for U.S. states from 2010 to 2020.

## Visualisations Included
